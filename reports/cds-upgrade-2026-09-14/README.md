## 验证

- 84 项 CDS / 看板后端回归测试通过，包括接口、并发写入、失败保留与批次一致性。
- 10 项 Python 定价测试通过，包括公开 Markit / QuantLib 基准、计息返还、周末/NYM、结算及输入边界。
- 全量 98 条记录最大价格回算残差约 1.04e-10（每 100 面值的价格单位）；该检查验证内部数值一致性，不证明市场准确度。
- 对比刷新前后，原始工作簿 SHA-256 相同，快照除对比字段外完全相同。证据见 `live-verification.json`。
- 前端生产构建通过；桌面表格、7 条历史展开、手机主表及历史表横向滚动、失败提示与保留上次结果均通过浏览器检查，页面脚本错误为 0。
- 独立复核发现的容器 libc、缺失原始记录、解释器覆盖配置三项问题已修复并复核通过。
- 当前 API 服务已保留启动配置重载；接口健康检查通过，定时 CDS 更新已绑定新引擎。见 `runtime-verification.json`。
