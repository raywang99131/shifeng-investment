# 板块新闻 Plan

更新时间：2026-07-01 00:37 CST

## 目标

把“新闻资讯”升级出一个“板块新闻”视图，重点回答：

今天哪些板块有催化，催化是什么，来自哪些新闻，对哪些 A/HK/US 相关公司可能有帮助。

## 初版板块池

- AI算力/数据中心
- 存储/HBM/DRAM
- 先进封装/CoWoS
- 半导体设备
- 半导体材料
- 消费电子
- 机器人
- 软件/AI应用
- 港股互联网
- A股消费
- 美股消费

后续可扩展：

- 电力
- 液冷
- 铜连接
- PCB
- MLCC
- 光模块
- AI金属/涨价链

## 标签设计

每条新闻不只打大类，还打两个核心标签：

- 板块：例如 存储/HBM/DRAM
- 催化类型：例如 涨价、订单、业绩、政策、新品、资本开支、供给收缩、大客户变化、并购、股价异动

示例：

高盛6月DRAM调查：大幅上调HBM2027年价格预期

- 板块：存储/HBM/DRAM
- 催化：涨价 / 价格预期上修

## 数据源原则

所有新闻源都可以贡献板块新闻，不按来源固定板块：

- Wall Street CN
- 36Kr
- Yahoo Finance
- Investing
- CTEE
- x_opencli
- 公告监控
- 后续行业网站

判断逻辑以新闻内容本身为准。

## 实现步骤

1. 后端新增 sectorNews 聚合逻辑，把现有新闻按“板块 + 催化”重新打标签。
2. 前端新增“板块新闻”tab，按板块卡片展示。
3. 第一版先覆盖 AI产业链和消费两大方向，验证有效后扩板块词典。
4. 排序按催化强度，不纯按时间。

## 排序权重

高权重：

- 涨价
- 供给收缩
- 大客户订单
- 业绩指引上修

中权重：

- 资本开支
- 新品
- 合作
- 政策

低权重：

- 普通观点
- 评论
- 弱相关股价异动

## MVP 建议

优先做 5 个板块：

- AI算力/数据中心
- 存储/HBM/DRAM
- 先进封装/CoWoS
- 半导体材料
- 消费电子

第一版目标不是完美，而是每天稳定回答：

今天哪些板块有催化，催化是什么，来自哪些新闻。
